Live launchd timer-precision check on this macOS 15.5 host (Apple Silicon), gui/<uid> domain.
Both agents were rendered by the product's own fm_remote_job_render_launchagent: one from the base commit 9a429a42 (no ProcessType), one from the head commit 8b5c3353 (ProcessType=Interactive).
Only the throwaway label and a disposable root/home differ. The lab worker script ($LAB/root/bin/fm-remote-job-worker.sh) runs python3 in a child process: 50x time.sleep(0.01), and a SQLite connect(timeout=0.5) against a held exclusive lock.
